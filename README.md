# Stanislav 3D

Адаптивное портфолио 3D-дизайнера: главная, работы и контакты.

- Семантический HTML, CSS Grid и Flexbox, анимации и адаптивное меню.
- Слайдер с управлением с клавиатуры, свайпом и паузой.
- Фильтрация работ по направлениям.
- Импорт собственной FBX-модели, вращение, масштаб, сетка и выбор цвета в Three.js.
- Проверка формы и скачивание подготовленной заявки. Отправка на почту не подключена.

## Локальный запуск

```sh
node server.cjs
```

Откройте http://127.0.0.1:4173. Также подходит VS Code Live Server.
Three.js включён в проект и не требует CDN. Для 3D нужен браузер с WebGL.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`.
Все пути относительные, поэтому сайт работает в подпапке репозитория.

Подробное описание требований и управления — в [README.txt](README.txt).
