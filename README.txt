STANISLAV 3D — МНОГОСТРАНИЧНОЕ ПОРТФОЛИО

ЗАПУСК
В папке проекта выполните: node server.cjs
Откройте http://127.0.0.1:4173
Альтернатива: расширение Live Server в VS Code.
Не открывайте HTML двойным щелчком: импорт FBX требует HTTP-сервера.
Node.js нужен только для локального сервера; сборка и npm install не нужны.
Three.js 0.179.1 и зависимости сохранены в vendor/three, интернет не требуется.
Лицензия библиотеки: vendor/three/LICENSE.

СТРАНИЦЫ
index.html — главная, слайдер реальных работ, направления и избранный проект.
portfolio.html — две работы, фильтры, галереи и интерактивная FBX-модель.
contacts.html — форма подготовки заявки с валидацией.

СООТВЕТСТВИЕ ЗАДАНИЮ
HTML: три страницы; header, nav, main, section, article, aside, figure, footer;
одинаковая навигация, текущая страница обозначена aria-current.
CSS: общий стиль, Grid и Flexbox, адаптивность, переходы и анимация appear;
видимый фокус и поддержка prefers-reduced-motion.
JavaScript: мобильное меню (Escape и закрытие вне меню), слайдер с кнопками,
точками, паузой, стрелками и свайпом; пауза при фокусе/наведении;
фильтрация проектов с обновлением количества и URL; валидация полей формы.
Three.js: импорт собственной models/gun_low.fbx через FBXLoader,
OrbitControls, вращение и масштаб, автовращение, каркас, цвет и сброс вида.
Стрелки на сфокусированной 3D-сцене вращают модель, + и - меняют масштаб.

ФОРМА
Имя: минимум 2 символа. Email: проверка формата. Тема: обязательна.
Сообщение: минимум 10 символов. Ошибки связаны с полями через aria-describedby;
при неуспешной проверке фокус переносится на первое ошибочное поле.
После проверки браузер скачивает project-request.txt. Поля не очищаются.
Отправки на почту нет: реальный адрес и серверный обработчик не предоставлены.
Для рабочей отправки потребуется подключить серверный endpoint или сервис форм,
с серверной валидацией. Не помещайте секреты почтового сервиса в браузерный JS.

3D
Модель показывается с нейтральным изменяемым материалом. Изображения в images
содержат авторские рендеры; текстуры из рендеров отдельно в проекте отсутствуют.
При недоступном WebGL отображается понятное сообщение; рендеры остаются доступны.
Цикл рендера приостанавливается, когда сцена вне экрана или вкладка скрыта.

ФАЙЛЫ
css/style.css — адаптивный стиль всех страниц.
js/main.js — общая навигация.
js/slider.js — слайдер.
js/portfolio.js — динамическая фильтрация.
js/form.js — валидация и скачивание заявки.
js/three.js — 3D-сцена и управление.
server.cjs — локальный сервер без сторонних зависимостей.

ПРОВЕРКА
В браузере проверены загрузка FBX, переключение сетки, мобильное меню и Escape,
фильтр брендинга, ошибки четырёх пустых полей и подготовка корректной заявки.
Проверены синтаксис JS и отсутствие ошибок загрузки 3D-библиотеки.
