Stanislav 3D

Сайт: https://krygliakovstudy-png.github.io/stanislav-portfolio/

Для запуска на компьютере: node server.cjs
Затем откройте http://127.0.0.1:4173.
Также подходит Live Server в VS Code.

В 3D-просмотре мышь вращает модель, колесо меняет масштаб.
После выбора сцены клавишей Tab работают стрелки и клавиши + / -.
Кнопки справа включают автовращение, сетку и возвращают начальный вид.

Форма проверяет заполненные поля и сохраняет заявку в текстовый файл.
Сообщения на почту не отправляются.

Структура проекта и сведения о Three.js описаны в README.md.
